# Changelog

## 0.1.0 - initial experimental release

- Added a local manifest builder for the database snapshot format observed in a Keepsafe iOS 11.11.1 extraction.
- Added a PowerShell recovery script that reads local media and key files and writes recovered copies to a separate folder.
- Added privacy, compatibility, troubleshooting, and GitHub publishing documentation.
- Compatibility beyond the tested extraction remains unverified.
